# Aadwik AI MVP v0.2

This project is an improved, build-oriented MVP for an Android AI movie-generation app.

## Included
- Flutter story input UI
- 4 animation styles
- English, Telugu, Hindi
- 1–30 minute selector
- Backend health endpoint
- Create/status/list/cancel/resume APIs
- Input validation
- Network timeouts and clearer errors
- Mock generation stages for end-to-end UI testing
- Docker backend

## Not yet included
Real AI video, TTS, lip sync, music, storage, PostgreSQL, Redis, Celery, authentication, or release signing. Those require choosing providers and configuring credentials/infrastructure.
